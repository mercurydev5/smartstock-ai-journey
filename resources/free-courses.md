## 🌟 Tier 1: Must-Do Courses (Phase 1-2)

### 1. Andrew Ng's Machine Learning Specialization ⭐⭐⭐
- **URL:** https://www.coursera.org/learn/machine-learning
- **Platform:** Coursera (Audit for FREE)
- **Duration:** ~3 months (at 5 hrs/week)
- **Language:** English
- **What you learn:** Linear regression, neural networks, clustering, anomaly detection
- **When to do:** Month 1-3
- **Note:** কোর্স audit করলে certificates পাবেন না, কিন্তু সব content free!

### 2. fast.ai: Practical Deep Learning for Coders ⭐⭐⭐
- **URL:** https://course.fast.ai
- **Platform:** fast.ai (FREE)
- **Duration:** 7 lessons (~20 hours)
- **Language:** English
- **What you learn:** Image classification, NLP, tabular data, deployment
- **When to do:** Month 3-4
- **Note:** Top-down approach - code first, theory later. Excellent!

### 3. Kaggle Learn ⭐⭐⭐
- **URL:** https://www.kaggle.com/learn
- **Platform:** Kaggle (FREE)
- **Duration:** Each micro-course: 4-8 hours
- **Language:** English
- **Courses to do:**
  - Python (if needed)
  - Pandas
  - Data Visualization
  - Machine Learning Intro
  - Feature Engineering
  - SQL
- **When to do:** Month 1-4 (alongside other courses)

### 4. Google ML Crash Course ⭐⭐
- **URL:** https://developers.google.com/machine-learning/crash-course
- **Platform:** Google (FREE)
- **Duration:** ~15 hours
- **Language:** English
- **What you learn:** ML fundamentals, TensorFlow basics
- **When to do:** Month 2

## 💡 How to Use These Courses

### Monthly Plan
```
Month 1: Andrew Ng Week 1-4 + Kaggle Python + Krish Naik basics
Month 2: Andrew Ng Week 5-8 + Kaggle ML Intro + CampusX
Month 3: Andrew Ng complete + fast.ai Part 1 start
Month 4: fast.ai Part 1 complete + Kaggle competitions
Month 5-6: Projects only (no new courses)
Month 7: CS231n (CNNs)
Month 8: CS224n Part 1 (NLP basics)
Month 9: CS224n Part 2 + Karpathy Zero to Hero starts
Month 10: HuggingFace NLP Course
Month 11: Karpathy GPT tutorial
Month 12: fast.ai Part 2
Month 13: DeepLearning.AI Short Courses (LangChain, RAG)
Month 14-15: LLM fine-tuning courses
Month 16-20: Build! No courses needed!
```

### ⚠️ Warning: Avoid Tutorial Hell!
```
❌ Don't watch courses passively
✅ Code along with every lecture
✅ After each section, build a small project
✅ Do the homework/assignments
✅ Apply concepts to Indian problems immediately
```
