## 📋 How to Use GitHub for Learning

### 1. Reading Code
```bash
# Clone and explore repos
git clone https://github.com/karpathy/nanoGPT
cd nanoGPT
# Read model.py first - main architecture
# Then train.py - training loop
```

### 2. Fork and Experiment
```bash
# Fork on GitHub, then clone YOUR fork
git clone https://github.com/YOUR-USERNAME/nanoGPT
# Make changes, train on Bengali data
git add . && git commit -m "Train on Bengali Wikipedia"
git push
```

### 3. Track Contributions
- Star repos you learn from
- Submit issues when you find bugs
- Make PRs (even small documentation fixes!)
- Contribute to AI4Bharat for Indic NLP

### 4. Build Your GitHub Profile
```
Target by end of 20 months:
✅ 50+ public repositories
✅ 500+ contributions (green squares!)
✅ Profile README with SmartStock AI link
✅ Pinned repos: SmartStock AI + best projects
✅ 100+ followers
```
