## 🆓 Free Online Books

### 1. Deep Learning (Goodfellow, Bengio, Courville) ⭐⭐⭐
- **URL:** https://www.deeplearningbook.org
- **Authors:** Ian Goodfellow, Yoshua Bengio, Aaron Courville
- **Level:** Intermediate to Advanced
- **When to read:** Month 5-8
- **Best chapters:** Linear Algebra (Ch2), ML Basics (Ch5), Deep Networks (Ch6), CNNs (Ch9), RNNs (Ch10)
- **Note:** Dense mathematical book - don't read start to finish. Reference specific chapters.

### 2. Mathematics for Machine Learning ⭐⭐⭐
- **URL:** https://mml-book.com
- **Authors:** Deisenroth, Faisal, Ong (Cambridge)
- **Level:** Intermediate
- **When to read:** Month 3-5 (alongside coding)
- **Topics:** Linear algebra, probability, optimization, PCA, SVMs, Gaussian processes

### 3. Dive into Deep Learning (d2l.ai) ⭐⭐⭐
- **URL:** https://d2l.ai
- **Authors:** Zhang et al. (Amazon)
- **Level:** Beginner to Advanced
- **When to read:** Month 4-10 (reference book)
- **Note:** Available in PyTorch, TensorFlow, JAX versions!
- **Best feature:** Runnable Jupyter notebooks for every chapter

### 4. Neural Networks and Deep Learning (Nielsen) ⭐⭐
- **URL:** http://neuralnetworksanddeeplearning.com
- **Author:** Michael Nielsen
- **Level:** Beginner
- **When to read:** Month 4-5
- **Note:** Best intuitive explanation of backprop. Short and clear.

### 5. Speech and Language Processing (Jurafsky & Martin) ⭐⭐⭐
- **URL:** https://web.stanford.edu/~jurafsky/slp3/
- **Authors:** Jurafsky & Martin (Stanford)
- **Level:** Intermediate to Advanced
- **When to read:** Month 8-10 (NLP chapters)
- **Best chapters:** Language Models (Ch3), RNNs (Ch9), Transformers (Ch10), BERT (Ch11)

### 6. Reinforcement Learning: An Introduction (Sutton & Barto) ⭐⭐
- **URL:** http://incompleteideas.net/book/the-book.html
- **Level:** Intermediate
- **When to read:** Optional, Month 14-15
- **Note:** The RL bible - read if interested in RLHF

## 💰 Paid Books (Worth Every Rupee!)

### 7. Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow ⭐⭐⭐
- **Author:** Aurélien Géron (3rd Edition, 2022)
- **Price:** ~₹2,500 (Amazon India)
- **Level:** Beginner to Advanced
- **When to read:** Month 2-6
- **Why it's worth it:**
  - Best practical ML book period
  - Covers everything: regression to deep learning to deployment
  - Full code examples in Python
  - Updated for TF2 and Keras
- **Buy link:** Search on Amazon India: "Hands-On Machine Learning Geron 3rd edition"

### 8. Deep Learning with Python ⭐⭐⭐
- **Author:** François Chollet (Keras creator, 2nd Edition)
- **Price:** ~₹2,000
- **Level:** Beginner to Intermediate
- **When to read:** Month 4-7
- **Why it's great:**
  - Written by Keras creator himself
  - Very intuitive explanations
  - Practical focus
  - Excellent for beginners

### 9. Build a Large Language Model From Scratch ⭐⭐⭐
- **Author:** Sebastian Raschka (2024)
- **Price:** ~₹3,500
- **Level:** Intermediate to Advanced
- **When to read:** Month 11-13
- **Why it's essential:**
  - Build GPT-2 from scratch, step by step
  - Fine-tuning chapter (instruction fine-tuning)
  - Very clear code
  - Perfect companion to Karpathy's course

### 10. Natural Language Processing with Transformers ⭐⭐⭐
- **Author:** Lewis Tunstall, Leandro von Werra, Thomas Wolf (Hugging Face team)
- **Price:** ~₹2,000
- **Level:** Intermediate
- **When to read:** Month 8-11
- **Why it's great:**
  - Written by HuggingFace engineers
  - Practical transformers implementation
  - Covers BERT, GPT, T5, and more
  - Real-world applications

### 11. Designing Machine Learning Systems ⭐⭐
- **Author:** Chip Huyen
- **Price:** ~₹2,500
- **Level:** Intermediate to Advanced
- **When to read:** Month 15-16 (before launch)
- **Why it's valuable:**
  - ML systems in production
  - Data pipelines, model deployment
  - Feature stores, monitoring
  - Real-world ML engineering

### 12. The Hundred-Page Machine Learning Book ⭐⭐
- **Author:** Andriy Burkov
- **Price:** ~₹1,000 (or free PDF on author's site)
- **URL:** http://themlbook.com (free to read, pay if you like)
- **Level:** Beginner to Intermediate
- **When to read:** Month 2-3
- **Why it's great:** Concise, clear, covers fundamentals in 100 pages

## 📚 Reading Strategy

### Phase 1-2 (Month 1-6):
```
Must Read:
- Hands-On ML (Géron) - chapters 1-10
- The Hundred-Page ML Book (first read-through)

Optional:
- Deep Learning with Python - chapters 1-5
```

### Phase 3-4 (Month 7-12):
```
Must Read:
- Deep Learning (Goodfellow) - chapters 6, 9, 10
- NLP with Transformers (HF team) - chapters 1-6
- d2l.ai - relevant chapters

Optional:
- Speech and Language Processing (Jurafsky) - chapters 3, 9, 10, 11
```

### Phase 5-7 (Month 13-20):
```
Must Read:
- Build LLM From Scratch (Raschka) - full book
- Designing ML Systems (Huyen) - chapters 1-8

Optional:
- RL: An Introduction (Sutton) - for RLHF understanding
```

---

## 💡 Reading Tips

1. **Don't read cover to cover** - Skip to relevant chapters
2. **Code along** - Never read theory without coding the examples
3. **Bengali notes** - Write key concepts in Bengali in your journal
4. **Teach it** - Explain each chapter in a LinkedIn post (in Bengali!)
5. **Return to basics** - Re-read math chapters when you get confused
