### Crystallized vs Fluid Intelligence
```
Fluid Intelligence (শিশুদের বেশি):
- নতুন patterns দ্রুত recognize করা
- Working memory
- Peak: 20-25 বছর

Crystallized Intelligence (বয়স্কদের বেশি): ✅
- Accumulated knowledge and skills
- Verbal ability, general knowledge
- Experience-based reasoning
- INCREASES with age!

আপনার advantage: Crystallized intelligence!
AI/ML শিখতে life experience অনেক কাজে আসে।
```

## 🃏 Spaced Repetition (Anki Method)

### What is it?
```
ভুলে যাওয়ার ঠিক আগে review করা = Long-term memory formation
```

### How to implement:
```
Day 1: Learn concept (e.g., backpropagation)
Day 2: Review - 5 minutes
Day 4: Review - 2 minutes
Day 8: Review - 2 minutes
Day 15: Review - 2 minutes
Day 30: Review - 2 minutes

Result: আপনি ৬ মাস পরেও মনে রাখবেন!
```

### Tools:
- **Anki** (free): https://apps.ankiweb.net
- Create flashcards for:
  - ML formula definitions
  - Code patterns
  - Paper key contributions
  - Bengali-English technical terms

```
Example Anki card:
Front: "What is the vanishing gradient problem?"
Back: "In deep networks, gradients become very small 
      during backpropagation, making early layers learn 
      very slowly. Solution: ReLU, ResNets, LSTMs"
```

## 🎯 Active Recall (Not Passive Reading!)

### Wrong Way:
```
❌ Read chapter → Re-read → Highlight → Move on
Result: Forget 90% within a week
```

### Right Way:
```
✅ Read section → Close book → Write what you remember
✅ Explain concept out loud (to yourself, rubber duck, anyone!)
✅ Teach it to someone else
✅ Write a blog post about it
Result: Remember 80%+ long-term!
```

### Practical application:
```python
# After learning backpropagation:
# DON'T: Just read the code
# DO: Close laptop, write from scratch

# Can you implement this from memory?
class Layer:
    def forward(self, x):
        # Write this from memory!
        pass
    def backward(self, grad):
        # Write this from memory!
        pass
```

## 📐 80/20 Rule: 20% Theory, 80% Practice

### How to structure your learning:
```
For every topic:
- 20%: Videos/articles/books (understand the concept)
- 80%: Coding, experimenting, building

Example - Learning LSTMs:
Day 1 (20%): 
  - Watch 3Blue1Brown LSTM video (20 min)
  - Read d2l.ai LSTM chapter (30 min)
Day 2-7 (80%):
  - Implement LSTM from scratch
  - Use PyTorch LSTM for festival prediction
  - Experiment with hyperparameters
  - Debug and improve
```

### Time allocation per month:
```
2 hours/day × 30 days = 60 hours/month

Breakdown:
- 12 hours (20%): Courses, reading, videos
- 48 hours (80%): Coding, projects, experiments
```

## ⏱️ Time Blocking & Pomodoro Technique

### Time Blocking:
```
Morning Block (Best for learning!):
6:00 AM - Wake up
6:15 AM - Exercise/yoga (30 min)
6:45 AM - Study: New concepts (45 min)
7:30 AM - Family time / breakfast
8:30 AM - Work starts

Evening Block:
9:00 PM - Study: Projects/coding (60 min)
10:00 PM - Review day's learning (15 min)
10:15 PM - Wind down, no screens
11:00 PM - Sleep (7+ hours!)
```

### Pomodoro for Deep Focus:
```
🍅 25 minutes: Focused coding/learning
🔔 5 minutes: Break (walk, water, stretch)
Repeat 4 times = 2 hours
🔔 15-30 min long break

Apps: Forest, Pomodoro Timer, Be Focused
```

### Morning vs Evening Learning:
```
Morning (Best for):
✅ Learning new complex concepts
✅ Math and problem-solving
✅ Writing code from scratch

Evening (Better for):
✅ Reviewing what you learned
✅ Working on ongoing projects
✅ Reading articles/papers
✅ Watching tutorials
```

## 🏥 Health is Wealth

### Sleep (Non-Negotiable):
```
7-8 hours minimum!
Why: Memory consolidation happens during sleep
Less sleep = learn 40% less effectively

Rule: Never sacrifice sleep for study.
Study less, sleep more = better learning
```

### Exercise:
```
30 minutes daily minimum
Why: Exercise increases BDNF (brain-derived neurotrophic factor)
= Literally grows your brain!

Best exercises for brain:
- Morning walk (fresh air + light)
- Yoga (stress reduction)
- Any cardio (blood flow to brain)

Bonus: Exercise is good thinking time!
Many breakthroughs happen during walks
```

### Diet for Brain Performance:
```
Brain foods:
🐟 Fatty fish (omega-3): Salmon, sardines, hilsa
🫐 Berries: Blueberries (antioxidants)
🥜 Nuts: Walnuts, almonds
🥚 Eggs (choline for memory)
☕ Green tea (L-theanine for focus)
💧 Water! (dehydration kills focus)

Avoid:
❌ Too much sugar (energy crashes)
❌ Processed foods (brain fog)
❌ Excessive caffeine after 2 PM
```

## 🔥 Avoiding Burnout

### Warning Signs:
```
- Learning feels like a chore
- Dreading your study time
- No excitement about projects
- Physical tiredness even after sleep
- Cynicism about goals
```

### Prevention:
```
1. Rest days (1 per week minimum!)
2. Vary your activities (code + read + watch)
3. Celebrate small wins
4. Connect with community
5. Remember your WHY (SmartStock AI!)
```

### Recovery:
```
If you burn out:
- Take 2-3 days complete break
- Don't feel guilty - rest is productive
- Come back with something fun/easy
- Review your WHY document
```
