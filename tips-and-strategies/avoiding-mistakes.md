## ❌ Mistake 1: Tutorial Hell

### What it looks like:
```
Week 1: "Andrew Ng course শুরু করলাম"
Week 2: "fast.ai-তে switch করলাম, better মনে হচ্ছে"
Week 3: "Krish Naik-এর YouTube দেখছি"
Week 4: "নতুন course খুঁজছি..."
Result: কোনো project নেই, কোনো progress নেই
```

### ✅ Correction:
```
Pick ONE course, finish it, then start a project.
"Done is better than perfect."

Rule: কোনো নতুন course শুরু করার আগে 
      একটি project complete করতে হবে।
```

## ❌ Mistake 2: Perfectionism Paralysis

### What it looks like:
```
"Perfect সময় আসলে শুরু করবো"
"আরো বেশি জানলে project বানাবো"
"এই concept আরো clearly বুঝলে..."
Result: কোনো project কোনোদিন শুরুই হয় না
```

### ✅ Correction:
```
"Done and mediocre > Perfect and never done"

Day 1 principle: আজকেই শুরু করুন, 
যা জানেন তাই দিয়ে।

Version 0.1 বানানোর পর improve করুন।
```

## ❌ Mistake 3: Comparing with Younger Learners

### What it looks like:
```
"ওই ২৩ বছরের ছেলেটা এতকিছু জানে..."
"আমি ৩১-তে শুরু করেছি, বেশি দেরি হয়ে গেছে"
"তারা তো degree ছিল, আমার কি..."
Result: Demotivation, giving up
```

### ✅ Correction:
```
আপনার advantages:
- ১০ বছরের life/work experience
- Real-world problems বোঝার ability
- Financial stability
- Emotional maturity
- Actual customer connections (kirana stores!)

৩১-বছরে শুরু করা = আপনার superpower!
See motivation.md for success stories.
```

## ❌ Mistake 4: Only Doing Courses, No Projects

### What it looks like:
```
Month 1-3: 5 courses finished ✓
Month 4-6: 3 more courses ✓
Month 7: Portfolio: EMPTY
Month 8: "আমার কোনো project নেই..."
```

### ✅ Correction:
```
For every course module:
→ Build something related, no matter how small

Rule: 1 course + 0 projects = wasted time
      0.5 course + 1 project = real progress

After Andrew Ng's ML course Week 2:
→ Implement linear regression on Indian house prices
→ Push to GitHub
→ Post on LinkedIn
```

## ❌ Mistake 5: Tool Hopping

### What it looks like:
```
Month 1: TensorFlow শিখছি
Month 2: "PyTorch better" - switch করলাম
Month 3: "JAX most modern" - switch করলাম
Month 4: "আসলে TensorFlow better" - back
Result: কোনোটাই ভালো করে শিখিনি
```

### ✅ Correction:
```
Pick: PyTorch → Stay with it for 2 years

The tool matters less than the concept.
PyTorch শিখলে TensorFlow-এ switch করতে 
1 সপ্তাহ লাগবে, ২ বছর না।

Exception: When a specific project REQUIRES another tool
```

## ❌ Mistake 6: Isolated Learning (No Community)

### What it looks like:
```
"আমি একা শিখি, community দরকার নেই"
"Reddit, Discord - সময় নষ্ট"
Result: 
- কোনো accountability নেই
- Questions unanswered থাকে
- No network for job/customer acquisition
```

### ✅ Correction:
```
Minimum community engagement:
- Weekly: 1 LinkedIn post about learning
- Monthly: 1 forum question or answer
- Quarterly: 1 local meetup attendance

Start small: Just lurk on Hugging Face Discord
Gradually participate in discussions
```

## ❌ Mistake 7: No Portfolio Building

### What it looks like:
```
Month 12 of learning:
GitHub: Empty (or only forks)
LinkedIn: No AI posts
Streamlit: No deployed apps
Result: "12 মাস শিখেছি কিন্তু দেখানোর কিছু নেই"
```

### ✅ Correction:
```
Every project → GitHub repo (with README!)
Every 3 projects → LinkedIn post
Every major project → Deployed demo
Every month → GitHub profile update

Target: By Month 6:
✅ 10+ GitHub repos
✅ 3+ deployed Streamlit apps
✅ 500+ LinkedIn followers
```

## ❌ Mistake 8: Math Obsession Before Practice

### What it looks like:
```
"Linear algebra পুরোপুরি বোঝার পর ML শুরু করবো"
"Calculus master করলে backprop বুঝবো"
"Statistics পরিষ্কার হলে..."
Result: 6 months on math, no ML done
```

### ✅ Correction:
```
Start with code → Math understand itself through practice!

Wrong order: Math → Theory → Code → Project
Right order: Code → Project → Theory → Math (as needed)

fast.ai approach: "Top-down learning works!"
Use sklearn's LinearRegression first,
understand the math AFTER you've used it
```

## ❌ Mistake 9: Not Asking for Help

### What it looks like:
```
Bug stuck for 3 days...
"Google করছি কিন্তু solve হচ্ছে না"
"ChatGPT-কে জিজ্ঞেস করতে লজ্জা"
"Forum-এ বোকার মতো প্রশ্ন হবে"
Result: Stuck, frustrated, losing momentum
```

### ✅ Correction:
```
The 20-minute rule:
Try for 20 minutes → If stuck, ASK for help

Where to ask:
- ChatGPT / Claude (fastest)
- Stack Overflow
- Hugging Face forums
- fast.ai community
- r/MachineLearning

"No question is stupid if you're genuinely learning"
```

## ❌ Mistake 10: Inconsistent Practice

### What it looks like:
```
Week 1: 20 hours! 🔥 Motivated
Week 2: 10 hours
Week 3: 3 hours (busy with work)
Week 4: 0 hours (gave up for now)
Week 5: "Restart করবো..."
Result: No compounding, no progress
```

### ✅ Correction:
```
Minimum viable practice: 30 minutes/day
Better: 2 hours/day

"Never miss twice" rule:
Miss Monday? Must study Tuesday!
A bad practice session > No practice session

Habit stacking: 
"After I brush teeth at night → 
 I open laptop and do 1 Pomodoro (25 min)"
```

## ❌ Mistake 11: Skipping Fundamentals to Jump to LLMs

### What it looks like:
```
"ChatGPT awesome! আমি directly LLM শিখবো"
"Python basics skip করে transformers tutorial"
"Math জানি না, কিন্তু Llama fine-tuning করবো"
Result: 
- Nothing makes sense
- Can't debug problems
- Copy-paste coder only
```

### ✅ Correction:
```
Foundation → Building → Advanced
Month 1-3: Python → NumPy → Pandas
Month 4-6: ML basics → DL basics
Month 7-10: CNN → RNN → Transformers
Month 11-13: LLM theory
Month 14+: Fine-tuning and RAG

Shortcuts don't work in AI.
Foundation is everything!
```

## ❌ Mistake 12: Not Deploying Any Project

### What it looks like:
```
"My model accuracy is 95%!"
"But it's only in a Jupyter notebook..."
"Deployment is hard, I'll do it later"
Result: Nothing to show to anyone
```

### ✅ Correction:
```
Always deploy, even the simplest version!

Free deployment options:
- Streamlit Community Cloud (Python apps)
- Hugging Face Spaces (ML demos)
- Vercel (Next.js/React)
- Render (backend APIs)
- GitHub Pages (static sites)

Rule: No project is "done" until deployed!
```
